Nesta pasta está contido o código final que utilizamos para o funcionamento do protótipo. Como mencionando anteriormente, tivemos que utilizar os dados que gravamos previamente, antes do headset apresentar problemas críticos, e, aqui, está a forma que encontramos para dar continuidade ao projeto com o que tínhamos. Nesse código, pegamos a onda, que deve estar salva na mesma pasta que o código, e fazemos um processo para que ele aparente estar "rodando" em tempo real, simulando um sinal de EEG captado ao vivo.
